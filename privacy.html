천명 개인정보처리방침

시행일: 2026년 9월 29일

1. 이 앱이 하는 일

천명 앱은 운영자 본인의 유튜브 채널(천명)에 운세 쇼츠 영상을 업로드·예약하고, 그 영상의 댓글에 답글을 달고, 조회수 통계를 확인하는 내부 운영 도구입니다. 운영자 본인 계정에서만 사용하며 외부 사용자에게 제공되지 않습니다.

2. 접근하는 Google 사용자 데이터

  • YouTube 업로드 권한(youtube.upload): 운영자 채널에 영상을 올리고 공개 시각을 예약합니다.
  • YouTube 관리 권한(youtube.force-ssl): 운영자 영상의 댓글을 읽고 답글을 답니다.
  • YouTube 분석 읽기 권한(yt-analytics.readonly): 운영자 채널의 조회수 통계를 읽습니다.

3. 수집·저장·공유

이 앱은 운영자 외 다른 사람의 개인정보를 수집하지 않습니다. 인증 토큰과 통계는 운영자 PC에만 저장되며 제3자에게 판매하거나 공유하지 않습니다. 광고 목적으로 사용하지 않습니다.

이 앱의 Google API 사용과 데이터 이전은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 삭제

Google 계정 → 서드파티 연결에서 언제든 앱 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없습니다.
